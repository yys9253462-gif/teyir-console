# 监控首页本地设计预览

本轮只修改本地前端，不部署、不推送、不接生产数据。预览入口使用明确标注的隔离示例数据，测速等请求也仅模拟响应。

## 设计方向

沿用 Teyir 苔绿主题：背景 #101411、面板 #151a16、正文 #e7ece6、强调 #c4f15b、警告 #f1b85a、故障 #ed7774。实际实现引用主题变量，兼容现有五主题。字体沿用 Noto Sans SC；数据表数字对齐，标题不另加字体。

页面围绕日常巡检组织：先看总体在线与待处理，再定位节点，最后比较流量与三网。以节点为主体，不把主机管理变成必经步骤。

```
节点监控                        刷新 / 立即测速
在线概况 | TCP延迟 | 出站流量 | 三网覆盖 | CPU | 内存
节点状态              搜索 / 地区 / 排序 / 卡片·列表
全部 / 需关注
节点卡片网格 或 可横向滚动的紧凑列表
流量分布                      全网三网质量
自动下线 / 被墙检测（沿用原功能）
```

审视后去掉了大幅装饰图、重复的英文编号和虚构趋势图：当前接口是状态快照，时间曲线会冒充不存在的数据。视觉重点放在明确的节点状态标签、资源条和四运营商对比。图表只表达近24小时流量总量，出入站以文字分别标注；缺失资源保留破折号，未测得保留占位和原因。

借鉴 Komari 的卡片/表格切换和资源条，自行实现，不复制外部主题代码。所有状态原因、测速、详情、自动下线与被墙检测入口继续保留。
